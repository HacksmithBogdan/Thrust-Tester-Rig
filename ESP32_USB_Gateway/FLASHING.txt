THRUST TESTER / ESP32-S3 ZERO USB GATEWAY

Target: Waveshare ESP32-S3 Zero, 4 MB flash. ESP-IDF firmware; not an Arduino .ino.

1. Disconnect the Nano and the external host-power feed from the ESP32 before
   connecting it to the computer. Avoid tying two independent 5 V supplies together.
2. Connect the ESP32 to the computer with a USB data cable.
3. Hold BOOT, tap RESET, release BOOT. Find the resulting COM port.
4. From PowerShell in this folder:
     powershell -ExecutionPolicy Bypass -File .\flash.ps1 -Port COM7
   Replace COM7 with the actual port. Python 3 is needed; the script installs
   esptool in a dedicated tools environment if necessary.
5. After boot, the USB port becomes a host and disappears as a computer COM port.
6. Power the ESP32 independently through a suitable regulated 5 V VBUS feed or
   correctly powered USB host adapter, then connect its USB data port to the Nano.
   A classic Nano normally DOES NOT feed 5 V back out of its USB connector.
   Check the actual board/cable arrangement; avoid connecting competing 5 V sources.
   The Zero Type-C connector has sink CC resistors, not a host power controller.
7. Join Wi-Fi: ThrustTester
   Password: ThrustRig-2026
   Open: http://192.168.4.1
   Keep the connection when the phone reports no internet.
8. Existing Nano firmware: enable DEBUG and match its serial baud (9600 default;
   Schubler calibration sketch uses 115200). Change gateway baud in Device settings.

Monitoring, plots, ESP32 recordings, saved-run viewing, CSV export and local CSV
import work with the original debug stream. USB calibration requires the later
Nano protocol update and remains disabled until that Nano advertises support.

Runs are stored in ESP32 flash, not on the Nano's SD card. They continue when the
phone disconnects. Stop a run before viewing/downloading it. Export CSV and
metadata before deleting a run. The finite storage meter is shown in the app;
recording stops near 75% filesystem usage. No old Nano SD files are exposed yet.

This flash command writes bootloader, partition table and application only. It
does not erase the settings or recording partitions. Do not use erase_flash
unless you intend to remove every saved run and all settings.

Firmware is software-validated; USB enumeration, board power, and measurements
must still be verified on the actual rig. Keep propulsion power off for hookup.

If the hotspot does not appear after flashing, release BOOT and press RESET,
or unplug/reconnect USB without holding BOOT, to leave download mode.
